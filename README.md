### About Me

- Founder & Lead Engineer at **[Orange Future Tech](https://orangefuturetech.com)** — industrial electronics, robotics, and STEM automation
- Building the **[CardGen ID Platform](https://cardgen.orangefuturetech.com)** — enterprise-grade credential & identity management
- Author of the **[Unitree Z1 Robotic Arm SDK](https://github.com/ShashankJangid/Unitree_Z1_SDK)** — precision C++/Python control stack
- End-to-end **MLOps pipelines** with Hugging Face, Docker, W&B, and GitHub Actions
- Deep learning researcher — seismic intensity prediction, EDA on large real-world datasets

---

### What I Build

- **Industrial Robotics** — Low-level motor control, high-level kinematic motion planning, and real-time arm controller interfaces for the Unitree Z1
- **Enterprise Software** — Production document management systems, ID card generation platforms, and scalable B2B web applications
- **AI / ML Pipelines** — End-to-end model training, fine-tuning, Dockerized inference, experiment tracking, and CI/CD automation
- **Full-Stack Web** — TypeScript / Next.js applications from STEM kiosks to logistics portals, deployed globally on Vercel
- **STEM & Education Tech** — Interactive hardware-software platforms for schools and industrial training programs
