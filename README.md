### What I Work On

- **Industrial Robotics** — Precision motion planning and real-time motor command interfaces for the **Unitree Z1** robotic arm via custom **C++** and **Python** SDKs; CAN bus communication and low-level joint control
- **Enterprise Software** — Production-ready **document management systems**, **ID card generation & credential platforms**, and multi-tenant B2B web applications built for scale
- **AI / ML & MLOps** — End-to-end training pipelines using **Hugging Face**, **PyTorch**, and **TensorFlow**; containerized inference with **Docker**, experiment tracking via **Weights & Biases**, fully automated through **GitHub Actions**
- **Computer Vision** — **OpenCV**-based object tracking, image processing pipelines, and visual data systems for robotics applications
- **Full-Stack Web** — High-performance **TypeScript / Next.js** applications deployed on **Vercel** — from interactive STEM education kiosks to enterprise logistics portals
- **STEM & Industrial Education** — Founder of **[Orange Future Tech](https://orangefuturetech.com)**, delivering hardware-software solutions for industrial training, automation, and engineering education

### Featured Projects

- **[Unitree Z1 Robotics SDK](https://github.com/ShashankJangid/Unitree_Z1_SDK)** — Author and maintainer of a precision control SDK for the Unitree Z1 arm supporting high-level kinematic planning and low-level motor commands in C++ and Python
- **[CardGen ID Platform](https://cardgen.orangefuturetech.com)** — Enterprise credential and identity card generation system built for high-throughput institutional use
- **[Enterprise DMS](https://github.com/ShashankJangid/enterprise-dms)** — Industrial document management system with role-based access control, audit trails, and full REST API
- **[Orange Future Tech Platform](https://orangefuturetech.com)** — Official company platform for industrial automation, robotics R&D products, and STEM engineering solutions
- **[MLOps Pipeline](https://github.com/ShashankJangid/MLOps-Pipeline)** — Complete HuggingFace fine-tuning → Dockerized inference → GitHub Actions CI/CD → W&B experiment tracking pipeline
- **[Deep Learning — Seismic Prediction](https://github.com/ShashankJangid/Deep-Learning)** — Neural network model predicting earthquake intensity from seismic telemetry data
